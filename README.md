# Andyhair Monorepo

A monorepo containing the frontend and backend for Andyhair application.

## Structure

- `frontend/` - Next.js frontend application
- `backend/` - NestJS backend application

## Getting Started

### Frontend

```bash
cd frontend
pnpm install
pnpm dev
```

### Backend

```bash
cd backend
pnpm install
pnpm start:dev
```
